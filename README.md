# Мини-прайс-бот

Тестовое приложение на Node.js 20, TypeScript strict, Express и React + Vite.
Рассчитывает цены по конкурентам и показывает таблицу «было / стало».

Проект создан с нуля: типы, пять примеров и JSON-данные подготовлены по условиям задания.

## Установка и тесты

Нужен **Node.js 20** (проверено на 20.20.2). Версия указана в `.nvmrc`.

```bash
npm install
npm test
```

`npm test` запускает `vitest run`. Тесты проверяют пять примеров ниже,
границы min/max, пустой список, отсутствие товара у конкурента, нулевой и дробный
шаг, одинаковые минимумы, независимость от `myPrice`, отсутствие мутаций и сверку
всего `data/products.json` с `data/expected.json`. Отдельные HTTP-тесты проверяют
API, порядок результатов, CORS и валидацию.

## Запуск

Сервер и фронтенд одной командой, без дополнительных зависимостей:

```bash
npm run dev
```

Открыть **http://localhost:5173**. API слушает **http://localhost:3001**.
`Ctrl+C` останавливает оба процесса; при завершении одного второй также останавливается.

Либо в двух терминалах:

```bash
npm run server
```

```bash
npm run web
```

Фронтенд берёт товары из `data/products.json`, отправляет `POST /reprice` и показывает
результаты API. В `web/vite.config.ts` настроен proxy `/reprice` на порт 3001.
Есть состояния загрузки, ошибки и кнопка повторного пересчёта.

```bash
npm run typecheck
npm run build
```

Сборка фронтенда появится в `web/dist/`. Vite proxy работает в режиме разработки;
для размещения production-сборки нужно направить `/reprice` на API через свой reverse proxy.

## Правила расчёта

Чистая функция `calculatePrice(product: Product): PriceResult` находится в
`src/pricing.ts`, типы — в `src/types.ts`.

1. Учитываются только конкуренты с `inStock: true`.
2. Если таких нет, новая цена равна `maxPrice`, причина — `NO_COMPETITORS`.
3. Иначе `best` — минимальная цена доступного конкурента,
   `candidate = Math.floor(best - step)`.
4. Если `candidate < minPrice`, возвращаются `minPrice` и `AT_MIN`.
5. Если `candidate > maxPrice`, возвращаются `maxPrice` и `AT_MAX`.
6. В остальных случаях возвращаются `candidate` и `UNDERCUT`.
   Равенство `minPrice` или `maxPrice` относится к `UNDERCUT`.

`oldPrice` всегда равна `myPrice`. Текущая цена не влияет на расчёт новой.
Входной объект и список конкурентов не изменяются.

### Пять примеров

Все примеры находятся в `data/products.json`, ожидаемые результаты — в `data/expected.json`.
Цены приведены в условных денежных единицах. «Нет» означает отсутствие товара у конкурента.

| SKU / название | Было | Min / Max | Шаг | Цены конкурентов (в наличии) | Candidate | Стало | Причина |
| --- | ---: | --- | ---: | --- | ---: | ---: | --- |
| TEA-01 / Чай | 120 | 80 / 150 | 5 | 110 (да), 125 (да) | 105 | 105 | UNDERCUT |
| COFFEE-02 / Кофе | 140 | 100 / 180 | 10 | 105 (да) | 95 | 100 | AT_MIN |
| COCOA-03 / Какао | 130 | 90 / 160 | 5 | 200 (да) | 195 | 160 | AT_MAX |
| HONEY-04 / Мёд | 200 | 150 / 250 | 10 | 170 (нет) | — | 250 | NO_COMPETITORS |
| MILK-05 / Молоко | 90 | 60 / 120 | 2.5 | 89.9 (да), 30 (нет) | 87 | 87 | UNDERCUT |

## API

`POST /reprice` принимает JSON-массив `Product[]` и возвращает `PriceResult[]`
в исходном порядке. Пустой массив допустим и возвращает `[]`.

```json
[
  {
    "sku": "TEA-01",
    "name": "Чай",
    "myPrice": 120,
    "minPrice": 80,
    "maxPrice": 150,
    "step": 5,
    "competitors": [{ "price": 110, "inStock": true }]
  }
]
```

Ответ:

```json
[
  { "sku": "TEA-01", "oldPrice": 120, "newPrice": 105, "reason": "UNDERCUT" }
]
```

Пример из корня проекта при запущенном API:

```bash
curl -X POST http://localhost:3001/reprice -H "Content-Type: application/json" --data-binary @data/products.json
```

В Windows PowerShell используйте `curl.exe` вместо `curl`.

Валидация возвращает HTTP 400 с `{ "error": "..." }`, если тело не массив,
JSON повреждён или хотя бы один товар некорректен. `sku` и `name` должны быть
непустыми строками. Цены и шаг — конечные неотрицательные числа, `minPrice <= maxPrice`.
`competitors` должен быть массивом объектов с конечной неотрицательной `price`
и логическим `inStock`. Числовые строки не преобразуются в числа.
Лимит JSON-запроса Express — 100 КБ; превышение возвращает HTTP 413.
